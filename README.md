# The diabetes-TB gap in India's States

Work in progress (Task 1 of the implementation plan): scaffold, source manifest
and a structure-only data inventory. No estimate has been computed.

A pre-registered, reproducible State-level analysis of India's diabetes-TB
screening and detection gaps (data years 2018, 2019, 2021, 2022 and 2023), from the India TB
Report diabetes tables and the NFHS-5 State fact sheets. The analysis plan,
`docs/analysis_plan.md`, will be pushed to the public repository before any
estimate is made.

- Design: `docs/superpowers/specs/2026-11-21-tb-diabetes-gap-design.md`
- Plan: `docs/superpowers/plans/2026-11-21-tb-diabetes-gap.md`
- Sources: `data/source_manifest.csv` (copied and verified by
  `python -I tools/fetch_sources.py`; `data_raw/` is not distributed)
- Data inventory: `docs/data_inventory.md`
